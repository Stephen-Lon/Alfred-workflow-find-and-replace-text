# Alfred-workflow-find-and-replace-text
Find and replace a word or phrase in text

> [!IMPORTANT]
> This workflow is designed for Alfred 6.0 and later. It will not work with earlier Alfred versions. If you are using an earlier version of Alfred use [version 2025.1](https://github.com/Stephen-Lon/Alfred-workflow-find-and-replace-text/releases/tag/2025.1) of this workflow.
